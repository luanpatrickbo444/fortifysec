# FortifySec V5 — mudanças

## Padrão visual interno
- Academy, Labs, Challenges, Ranking e Perfil usam o mesmo design system do cyber range.
- Navegação lateral agora marca a rota ativa.
- Cards ganharam estados ativos, bloqueados, running e pwned.
- Indicador visual de dificuldade em Labs e Challenges.

## Feedback em ações reais
- Iniciar Lab: `PROVISIONANDO LAB...` + spinner + bloqueio de clique.
- Encerrar Lab: `ENCERRANDO...`.
- Enviar flag: `VALIDANDO FLAG...`.
- Comprar curso: `ABRINDO CHECKOUT...`.
- Salvar perfil: `SALVANDO PERFIL...`.
- Concluir aula: `SALVANDO PROGRESSO...`.
- Publicar aula no Admin: `PUBLICANDO AULA...`.

## Telas restauradas/refeitas
- Workspace completo do Lab.
- Workspace de Challenge.
- Ranking com pódio Top 3.
- Perfil técnico com nível, XP, rank e métricas.
- Academy com progresso real por curso.
- Content Studio no painel administrativo para postagem de aula.
- Página pública de planos: Grátis e Pro R$ 99,90/mês.

## Observação sobre planos
A página de planos foi restaurada como interface pública. A ativação financeira continua usando os fluxos autenticados já existentes no projeto; esta V5 não altera silenciosamente o modelo financeiro para cobrança recorrente automática.

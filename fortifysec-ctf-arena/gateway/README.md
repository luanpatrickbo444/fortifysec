# FortifySec Arena - Lab Gateway

Gateway de acesso individual aos laboratórios.

Objetivos:
- Autenticação pelo CTFd.
- Autorização por usuário e laboratório.
- Resolução interna da porta Docker.
- Bloqueio de sessões expiradas.
- Encaminhamento HTTP seguro.
- Suporte futuro a WebSocket.
- Sem exposição pública das portas dos laboratórios.

Ambiente inicial: homologação.

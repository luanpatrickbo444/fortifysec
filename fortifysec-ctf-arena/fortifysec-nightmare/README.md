# FortifySec Nightmare FS-016..FS-025

Protótipos de 10 laboratórios independentes com respostas técnicas e flags únicas geradas por container. **Não são desafios de nível impossível ainda**: precisam de maior profundidade para competição.

Execute no Kali `sudo bash deploy.sh` dentro desta pasta. Faz backup dos dois scripts em `/opt/fortifysec-nightmare-backups/` e compila as imagens. Não altera o CTFd, MariaDB, Cloudflare ou containers em execução.

**Integração pendente:** catálogo/UI do portal Labs e registro central de flags; os códigos desses componentes não foram fornecidos. O Manager reconhecerá os novos IDs após instalar. Limite atual de 1 Lab por aluno e 10 sessões globais continua.

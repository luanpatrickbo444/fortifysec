# FortifySec Elite Labs — Lote 03

20 desafios offline FS-013 a FS-031 (exceto FS-032), mais FS-033.

PARTICIPANTES contém 20 ZIPs independentes. ADMIN_PRIVADO contém flags e soluções e **não deve ser disponibilizado publicamente**.

Os desafios Web são análise de cliente local, e não serviços vulneráveis implantados. Os ELF são para análise estática/dinâmica, não para exploração de memória. As capturas de rede são PCAP sintéticas reais.

Dependências de produção: GCC para construir os binários (já compilados), Python 3; para resolver, Wireshark/tshark, sqlite3, Ghidra/GDB opcionais.

QA automatizado: integridade dos ZIPs, contagem, flags únicas, assinatura ELF e PCAP, abertura do SQLite, consistência de metadados. **Não equivale a resolução independente ou homologação internacional**.
